# 淘宝用户行为分析

## 数据
- 来源：UserBehavior.csv（2017-11-25 至 2017-12-03）
- 采样：5 万随机用户
- 行为类型：点击、收藏、加购、购买

## 技术栈
Python · Pandas · NumPy · Matplotlib · Seaborn

## 分析模块
1. **流量、时序与转化漏斗**  
   - 每日 UV/PV 及人均 PV 趋势  
   - 24 小时行为分布  
   - 全站浏览→购买转化漏斗  

2. **用户留存与动态复购**  
   - 次日～7 日留存衰减曲线  
   - 购买行为路径分布  
   - 复购周期分布与流失预警线  

3. **精细化 CRM 与品类诊断**  
   - RF 客户分层（价值/忠诚/潜力/流失风险）  
   - 品类流量-转化波士顿矩阵  
   - 高频品类交叉销售共现矩阵
